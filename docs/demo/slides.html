01 // The problem

Two satellites // two counts

  • MODIS (2000 →) and VIIRS (2012 →) see the same fires at different resolutions.
  • Joined naively, fire seems to jump in 2012: a new instrument, not more burning.
  • MODIS is ending; the record must continue on VIIRS.
Raw counts per sensor, Punjab: the instruments don't line up, so “is this month unusual?” gets hard to answer.

02 // Method

Fire calendar // exploded view

  • Aqua MODIS and Suomi NPP VIIRS both pass at 13:30, so their counts compare fairly.
  • Unit: the fire cell-day. A burning H3 cell on one day counts once, which removes most of the pixel-size gap.
  • Ratios per 2° block × month × day/night, pulled toward the national ratio when sparse, each with a 90% bootstrap interval.
  • Terra (2000–02) and NOAA-20 (2026 →) are chained in.
